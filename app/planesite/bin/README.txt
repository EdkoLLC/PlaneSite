turbojpeg.dll: TurboJPEG library from libjpeg-turbo 3.1.4.1 (https://libjpeg-turbo.org),
built for 64-bit Windows with SIMD. Used to decode only the needed rows of each photo while
rendering. License: turbojpeg-LICENSE.md (IJG / modified BSD / zlib).

libturbojpeg.dylib: the same TurboJPEG library (libjpeg-turbo 3.2.1) for macOS on Apple Silicon
(arm64), from conda-forge (libjpeg-turbo-3.2.1-hb001647_0, osx-arm64). Only depends on macOS's
libSystem. Same license.
